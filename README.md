# このサイトに記事を出すしくみ

- 記事は `_posts/` に `2026-11-21-dry-food.md` のような名前で置くと、自動で公開されます。
  - 名前は「日付-英数字のタイトル.md」。日本語のファイル名は避けてください（URLが読みにくくなるため）。
- ひな形は `_drafts/記事のひな形.md`。`_drafts/` に置いたものは公開されません。
- 写真は `assets/images/` に入れて、本文で `![説明](/assets/images/写真.jpg)` と書きます。
- 記事の冒頭の「PR（広告を含みます）」表示は自動で入ります。広告リンクがない記事だけ `pr: false` にします。
- AI社員の下書き（`ai-company/記事/下書き/`）にある `【商品リンク：〇〇】` は、公開前に実際のリンクへ差し替えます。
